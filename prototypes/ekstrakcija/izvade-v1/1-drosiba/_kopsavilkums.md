# JV — 1. Drošība un aizsardzība

- Solījumi: 24
- Nepārbaudāmi: 10
- Ar abiem avotiem (CVK + paplašinātā): 10
- Ar `nesakritiba`: 8

## Jautājumi redaktoram

- `jv-aizsardzibas-finansejums-5-no-ikp`: Vai 3. nodaļas punktu (iekšējās UN ārējās drošības investīcijas vismaz 5%) apvienot šeit kā Nesakritību, vai atstāt atsevišķam Solījumam 3. nodaļas izpildē (CVK 3. nod. „drošību finansēsim atbildīgi“)?
- `jv-aizsardzibas-industrijas-eksporta-triskarsosana`: Vai tas ir CVK „Attīstīsim vietējo militāro … industriju, lai … stiprinātu … eksportu“ mērs (tad apvienot ar `jv-vietejas-militaras-industrijas-attistiba` un vērtēt pēc trīskāršošanas, §4), vai jauna atsevišķi izvērtējama darbība (kā tagad)?
- `jv-robezparkapeju-neielaisana`: Vai absolūto formulējumu „neļausim robežpārkāpējiem iekļūt Latvijā“ vērtēt kā pārbaudāmu vai kā nepārbaudāmu deklarāciju?
- `jv-augstskolu-slegsana-imigracijas-apiesana`: Vai šo 8. nodaļas punktu atstāt 1. nodaļas izpildē vai pārcelt uz „Ārpus CVK nodaļām“?

## CVK teikumi, kas netika izrakstīti

Nav — visi 7 nodaļas teikumi izrakstīti (6. teikums sadalīts 2 Solījumos, 7. teikums — 3 Solījumos, 1. teikums — 2 Solījumos).

## Paplašinātās programmas punkti, kas netika izrakstīti

1. nodaļa:
- „10 000 zīmju programmas apsolījums“ (CVK teksta kopija) — ignorēts (§0).
- Prioritāte „Aizsardzības spēju finansējums 5% apmērā …“ — atkārto Apņemšanās (§1).
- Prioritāte „NATO sabiedroto klātbūtnes palielināšana Latvijā un Baltijas reģiona drošības stiprināšana“ — atkārto.
- Prioritāte „Ukrainas kara pieredzē balstītas pretdronu spējas, robežas drošība un kritiskās infrastruktūras aizsardzība“ — atkārto.
- Prioritāte „Civilās aizsardzības, patvertņu, sirēnu un valsts materiālo rezervju sistēmas pilnveide“ — atkārto.
- Prioritāte „Iekšējās drošības dienestu kapacitāte, infrastruktūra un jauniešu piesaiste dienestam“ — atkārto.
- „Strādāsim spēcīgai un vienotai NATO aliansei, padziļinot … sadarbību ar … Kanādu un Amerikas Savienotajām Valstīm“ — atbilst CVK 2. nod. „Nostiprināsim Latviju Eiropas un NATO kodolā“ → 2. nodaļas izpildei.
- „Stiprināsim reģionālu drošības kodolu starp Baltijas valstīm, Ziemeļvalstīm un Poliju … NB8, JEF, NORDEFCO, BJVP … Arktikas drošības dimensiju“ — neatbilst nevienam CVK 1. nod. teikumam → 2. nodaļas izpildei (vai „Ārpus CVK nodaļām“).
- „Turpināsim visaptverošu atbalstu Ukrainai, tostarp militāro atbalstu vismaz 0,25% no IKP …“ — atbilst CVK 2. nod. atbalstam Ukrainai → 2. nodaļas izpildei.
- „Konsekventi uzturēsim prasību, lai agresors maksātu pilnu cenu … sankcijas“ — atbilst CVK 2. nod. spiedienam pret Krieviju → 2. nodaļas izpildei.
- „Attīstīsim tehnoloģisko pārākumu, Latviju kā inovāciju laboratoriju … autonomo sistēmu tehnoloģijām, 5G un 6G …“ — atbilst CVK 7. nod. „Prioritāri attīstīsim aizsardzības tehnoloģijas …“ → 7. nodaļas izpildei.
- „Stiprināsim starptautisko tiesisko kārtību atbilstoši ANO Statūtiem …“ — atbilst CVK 2. nod. (vai 10. nod.) → turpmākai izpildei.
- „Iestāsimies par lielāka Eiropas Savienības finansējuma pieejamību austrumu robežas un reģiona drošībai“ — atbilst CVK 2. nod. „ES daudzgadu budžeta sarunās aizstāvēsim finansējumu drošībai, robežai …“ → 2. nodaļas izpildei.
- Pamatojums (2 rindkopas) — neizraksta (§1).

Citas nodaļas (izskatīti kā iespējami atbilstoši, bet neizrakstīti):
- 2. nod. „Panāksim turpmāku Eiropas Savienības aktīvu atbalstu un finansējumu ārējo robežu aizsardzībai …“ — atbilst CVK 2. nod. ES budžeta teikumam → 2. nodaļas izpildei.
- 3. nod. prioritāte „Iekšējās un ārējās drošības investīciju finansēšana vismaz 5% …“ — atkārto 3. nod. Apņemšanos (citēta `jv-aizsardzibas-finansejums-5-no-ikp`).
- 4. nod. prioritātes „… trīskāršojot Latvijas aizsardzības industrijas eksporta apjomus“ un „Valsts enerģētiskā drošība un vietējās aizsardzības industrija kā galvenā … dzinējs“ — atkārto Apņemšanās.
- 4. nod. „Izveidosim paātrinātus tiesiskos un administratīvos koridorus enerģētikas, aizsardzības …“ — atbilst CVK 4. nod. investīciju koridoriem → 4. nodaļas izpildei.
- 4. nod. „Pārveidosim valsts iepirkumu sistēmu par stratēģisku instrumentu …“ (sadaļā „Aizsardzības industrija“) — atbilst CVK 4. nod. „valsts pasūtījumu kā instrumentu“ → 4. nodaļas izpildei.
- 4. nod. pārējās punkta „Panāksim pastāvīgu produktivitātes pieaugumu virs 3% gadā …“ daļas — 4. nodaļas izpildei.
- 5. nod. „Stiprināsim veselības sektora gatavību krīzēm …“ — atbilst CVK 5. nod. „krīzes gatavību“ → 5. nodaļas izpildei.
- 9. nod. prioritātes „Latvijas austrumu pierobežas stiprināšana …“ un „Autonomi krīzes vadības centri, patvertņu tīkls un vienota iekšējās drošības sadarbība pašvaldībās“ — pirmā → 9. nodaļas izpildei, otrā atkārto Apņemšanās.
- 9. nod. ceļi pierobežā (ar NBS kustību), ostas (militārā mobilitāte), duālas lietojamības ceļi un tilti — atbilst CVK 9. nod. satiksmes teikumam → 9. nodaļas izpildei.
- 10. nod. „Turpināsim stiprināt valsts un sabiedrības drošību, stingri vēršoties pret Krievijas … hibrīdapdraudējumiem …“ un stratēģisko investoru (arī aizsardzības jomā) paātrinātās atļaujas — 10. nodaļas / „Ārpus CVK nodaļām“ izpildei.
